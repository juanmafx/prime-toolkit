# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| Earlier unversioned scripts | No |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting on this repository if it is available. If it is not, open an issue that asks for a private contact channel and leave out exploit details.

## Scope and intended use

This project is a study and research tool. It must not be used to generate production cryptographic keys: it has not been audited, its arithmetic is not constant-time, and seeded runs are deterministic by design.
